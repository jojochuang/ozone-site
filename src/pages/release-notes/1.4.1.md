# Release Notes for Ozone 1.4.1

Apache Ozone 1.4.1 was released on March 31st, 2025. This maintenance release includes 227 commits addressing bug fixes, performance improvements, and stability enhancements on top of Ozone 1.4.0.

## Notable Changes

### Stability and Bug Fixes

- [HDDS-11491](https://issues.apache.org/jira/browse/HDDS-11491) - Avoid sharing clientId among deleting services
- [HDDS-11492](https://issues.apache.org/jira/browse/HDDS-11492) - Directory deletion get stuck having millions of directory
- [HDDS-11635](https://issues.apache.org/jira/browse/HDDS-11635) - Memory leak when using Ozone FS via Hadoop FileContext API
- [HDDS-11608](https://issues.apache.org/jira/browse/HDDS-11608) - Client should not retry invalid protobuf request
- [HDDS-11331](https://issues.apache.org/jira/browse/HDDS-11331) - Fix Datanode unable to report for a long time
- [HDDS-11223](https://issues.apache.org/jira/browse/HDDS-11223) - Fix iteration over ChunkBufferImplWithByteBufferList
- [HDDS-11136](https://issues.apache.org/jira/browse/HDDS-11136) - Some containers affected by HDDS-8129 may still be in the DELETING state incorrectly
- [HDDS-10918](https://issues.apache.org/jira/browse/HDDS-10918) - NPE in OM when leader transfers
- [HDDS-10777](https://issues.apache.org/jira/browse/HDDS-10777) - S3 Gateway error when parsing XML concurrently
- [HDDS-10780](https://issues.apache.org/jira/browse/HDDS-10780) - NullPointerException in watchForCommit

### Erasure Coding (EC) Improvements

- [HDDS-11482](https://issues.apache.org/jira/browse/HDDS-11482) - EC Checksum throws IllegalArgumentException because the buffer limit is negative
