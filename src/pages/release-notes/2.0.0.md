# Release Notes for Ozone 2.0.0

Apache Ozone 2.0.0 was released on April 30th, 2025. This release includes 1700 new features, improvements, and bug fixes on top of Ozone 1.4.

## Notable Features

### Supporting HSync and Lease Recovery

[HDDS-7593](https://issues.apache.org/jira/browse/HDDS-7593) - Added support for HSync and lease recovery to ensure data durability and consistency.

### SCM Decommissioning Support

[HDDS-7852](https://issues.apache.org/jira/browse/HDDS-7852) - Introduced Storage Container Manager (SCM) decommissioning capabilities for better cluster management.

### Symmetric Keys for Delegation Tokens

[HDDS-8829](https://issues.apache.org/jira/browse/HDDS-8829) - Implemented symmetric keys for delegation tokens to enhance security and performance.

### Atomic Key Overwrite and Key Replacement

[HDDS-10656](https://issues.apache.org/jira/browse/HDDS-10656) - Added atomic key overwrite and key replacement functionality for improved data consistency.

## Other Noteworthy Changes

### Platform Support

- [HDDS-6263](https://issues.apache.org/jira/browse/HDDS-6263) - ARM64 support
- [HDDS-8246](https://issues.apache.org/jira/browse/HDDS-8246) - Java 11/17/21 Support and Testing
- [HDDS-11577](https://issues.apache.org/jira/browse/HDDS-11577) - AWS SDK v2 client support

### Observability

- [HDDS-9307](https://issues.apache.org/jira/browse/HDDS-9307) - Ozone performance and operational dashboards
- [HDDS-11153](https://issues.apache.org/jira/browse/HDDS-11153) - Recon UI Improvements
- [HDDS-11825](https://issues.apache.org/jira/browse/HDDS-11825) - Support for interactive mode for Ozone CLI

### Developer Experience

- [HDDS-6729](https://issues.apache.org/jira/browse/HDDS-6729) - JUnit 4 to 5 upgrade
- [HDDS-8113](https://issues.apache.org/jira/browse/HDDS-8113) - Dropped Hadoop 2.7 ~ 2.9 support
- [HDDS-10986](https://issues.apache.org/jira/browse/HDDS-10986) - Publish SBOM artifacts
- [HDDS-11617](https://issues.apache.org/jira/browse/HDDS-11617) - Hadoop dependency updated to 3.4.1

## Incompatible Changes

- [HDDS-7307](https://issues.apache.org/jira/browse/HDDS-7307) - Move S3 Gateway web admin to separate port
- [HDDS-11753](https://issues.apache.org/jira/browse/HDDS-11753) - Deprecate file per chunk layout from Datanode code
- [HDDS-11754](https://issues.apache.org/jira/browse/HDDS-11754) - Drop support for non-Ratis OM and SCM
- [HDDS-11759](https://issues.apache.org/jira/browse/HDDS-11759) - Remove LegacyReplicationManager
